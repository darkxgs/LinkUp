# App Routes (expo-router)

File-based route tree. Each file/folder maps to a screen or navigation group. Groups in parentheses `(auth)` / `(tabs)` are layout groups that do not add a URL segment. `_layout.tsx` files define stack/tab navigators; `[param].tsx` files are dynamic routes.

## Files
- `_layout.tsx`
- `index.tsx`
- `notifications.tsx`
- `splash.tsx`
- `wealth-level.tsx`
