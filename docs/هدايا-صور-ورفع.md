# هدايا بصور مخصصة — دليل اللوحة

## من لوحة التحكم

1. **الهدايا** → **إضافة هدية**
2. اختر **صورة مخصصة** (بدل الأيقونة الجاهزة)
3. **رفع صورة** — تظهر في قائمة الهدايا بالغرفة (PNG/JPG/WebP، يُفضّل 256×256 شفاف)
4. **رفع GIF / أنيميشن** (اختياري) — يظهر عند الإرسال في الغرفة بنفس حركة الأيقونات
5. **حفظ ونشر للتطبيق** — يتحدّث `config/gifts` فوراً

يمكن لصق **رابط URL** بدل الرفع إن كانت الصور على CDN.

## Firebase Storage

المسار: `config/gifts/{giftId}/thumb.*` و `animation.*`

نشر القواعد (مرة واحدة):

```bash
cd linkup-functions
firebase deploy --only storage
```

يجب تسجيل الدخول في اللوحة قبل الرفع.

## حقول Firestore (`config/gifts.items[]`)

| الحقل | الوصف |
|--------|--------|
| `visualType` | `icon` \| `image` |
| `imageUrl` | صورة القائمة |
| `animationUrl` | GIF للغرفة (اختياري) |
| `iconName` / `iconColor` | fallback للأيقونة |

الهدايا القديمة بدون `imageUrl` تستمر كأيقونات Lucide.

## إذا ظهرت أيقونة هدية وردية بدل PNG

1. في اللوحة: تأكد أنك اخترت **صورة مخصصة** وليس **أيقونة جاهزة**
2. بعد **رفع صورة** يجب الضغط **حفظ ونشر للتطبيق**
3. في Firebase Console → `config/gifts` → تحقق أن العنصر يحتوي `imageUrl` برابط `https://firebasestorage...`
4. إن فشل الرفع: انشر قواعد Storage (`firebase deploy --only storage`) وسجّل دخولك في اللوحة
5. أعد فتح التطبيق (أو اسحب للتحديث في شاشة الهدايا)
