# مشرف الدولة — نطاق المحتوى

## السلوك

- **مدير النظام (`super`):** يرى كل الدول.
- **مشرف الدولة (`country`):** يرى فقط محتوى الدول المحددة في `admins/{uid}.countries` (مثل `PS`, `SA`, `EG`).

## أين تُطبَّق الفلترة

| القسم | المعيار |
|--------|---------|
| المستخدمون | `profile.country` / `country` |
| الغرف | `room.country` أو دولة المضيف |
| الوكالات + الطلبات | `country` / `countryCode` |
| المنشورات | دولة كاتب المنشور |
| السحب والمعاملات | دولة صاحب الطلب |
| العلاقات | أحد الطرفين من دول المشرف |
| الدعم | دولة المستخدم في المحادثة |
| البلاغات | دولة المُبلّغ |
| لوحة المعلومات والإحصائيات | نفس النطاق |

## الصلاحيات (أقسام القائمة)

كل قسم في الشريط الجانبي يظهر فقط إذا مُفعَّل في `permissions` للمشرف (مثل `users`, `rooms`, `agencies`).  
مدير النظام يرى كل الأقسام.

## ملاحظة

الإعدادات العامة (هدايا، باقات، إعدادات النظام) قد تبقى مشتركة — لأنها تكوين منصة وليست بيانات مستخدمين حسب الدولة.
