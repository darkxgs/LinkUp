# LinkUp

منصة دردشة صوتية اجتماعية عربية — غرف صوتية مباشرة، هدايا، ألعاب، تحديات 1v1، وكالات، ونظام VIP.

Arabic social live-audio platform — live voice rooms, gifts, casino & 1v1 challenge games, agencies, and a VIP system.

## Stack
- **App**: Expo 52 / React Native 0.76 · Firebase (Auth/Firestore/RTDB/Storage) · LiveKit (voice/video)
- **Admin**: React 18 · Vite · Firebase
- **Backend**: Firebase Cloud Functions · Firestore/RTDB rules · Firebase Hosting (webview games)
