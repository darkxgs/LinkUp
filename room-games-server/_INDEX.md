# Room Game Servers

Node realtime (WebSocket) servers for multiplayer room games, containerized for Cloud Run. `createServer.mjs` is the shared factory; per-game servers live in `games/`.

## Files
- `Dockerfile`
- `createServer.mjs`
- `deploy-cloud-run.sh`
- `index.js`
- `package-lock.json`
- `package.json`

## Subfolders
- `games/` — see `games/_INDEX.md`
- `public/` — see `public/_INDEX.md`
- `scripts/` — see `scripts/_INDEX.md`
