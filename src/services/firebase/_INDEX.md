# Firebase Data Access

One module per Firestore/Storage domain — the app's data layer. Covers users, rooms, seats, chat, gifts, agencies, challenges, casino stats/leaderboards, VIP/aristocracy, titles, wealth, posts, notifications, KYC, store, and config. `index.ts` re-exports; `config.ts` holds the Firebase app init.
