# LinkUp Mobile App

Expo / React Native client for the LinkUp social + live-audio-room platform. Routing is file-based via expo-router (screens live in `app/`), state via Zustand (`src/stores`), backend via Firebase (`src/services`), realtime voice/video via LiveKit, and i18n in English/Arabic with RTL support. Reusable UI and logic live under `src/`.
