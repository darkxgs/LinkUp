# تطابق الأشكال (Match the Shapes)
**Intelligence Games Suite - Game #2**

A premium, highly responsive single-page web game built with native HTML5, CSS3, and JavaScript.

## Features
- **Cyber-Neon Theme & Glassmorphism**: Stunning visual styling with neon grid backgrounds, dark glassmorphic card templates, and custom SVG shape drawings.
- **Synthesized Audio Engine**: Realistic retro arcade sound effects synthesized on-the-fly using the **Web Audio API** (CORS-safe and asset-free). Includes mute/unmute control.
- **Dynamic Particle System**: Full-screen canvas overlay generating floating background ambient dust, matching card spark bursts, and double-wave victory confetti.
- **High-Stakes & Custom Wagers**: Select preset bet amounts ($5,000, $10,000, $15,000, $20,000) or enter a custom amount.
- **Dynamic Challenge Scaling**: Shuffling speed automatically scales depending on the wager amount.
- **Interactive Statistics Panel**: View wager sizes, elapsed time, and total payouts on a clean scorecard layout at game end.
- **Daily Sessions Limit**: Simulated limit reset at local midnight with a live-ticking holographic lock countdown.

## Installation & Running
This project runs entirely client-side. To play, simply open `index.html` in any modern web browser or serve it locally using a lightweight server (e.g. Node.js `http` server).
